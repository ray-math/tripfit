# 같은 키트로 만든 카페·행사 예시

`high` 브랜치에서 만든 별도 앱입니다. 원본 `web/`와 `main`을 변경하거나, 원본 앱을 iframe으로 표시하지 않습니다. 이전에 조정한 88×32 CSS-pixel 목업 아일랜드와 완화한 pop 스프링을 그대로 공유합니다.

## 실행

- `examples/apps.html` / `dist/apps.html`: 예시 선택 화면
- `examples/cafe.html` / `dist/cafe.html`: SLOW MORNING — 카페 주문·픽업
- `examples/event.html` / `dist/event.html`: FIELD NOTES — 행사·시간표·데모 패스
- 기존 `gallery.html`, `lesson.html`도 유지됩니다.

정적 서버에서 `ui-kit/examples/`를 열거나 `python ui-kit/build_preview.py`로 만든 단일 HTML을 사용합니다. 실제 공개 사이트에서는 생성된 HTML을 GitHub Pages로 배포합니다. 모든 앱은 `ComposedFlow`, 공통 카드·버튼·상세 시트·모션·QR 모듈을 사용합니다.

## 카페

6개 예시 메뉴, 분류와 검색, 즐겨찾기, 품절 상태, 제품 종류별 옵션, 온도/크기/우유/디카페인/당도/데우기, 옵션별 가격 계산, 동일 옵션 병합, 1~9개 수량 제한, 장바구니 옵션 수정, 삭제와 실행 취소, 최소 금액·상한이 있는 쿠폰, 픽업 시점, 요청 메모, 명시적 데모 주문 확인, 4단계 픽업 상태 시연, 로컬 주문 기록, 재주문, 완료 스탬프, 데모 픽업 QR, 영수증 텍스트 내보내기, 공유/복사.

픽업 단계는 사용자가 버튼을 눌러 진행하는 시연입니다. 가격·재고·예상 시간·할인·스탬프에 실제 매장 연동이나 금전적 효력이 없습니다. 최근 12개 주문을 이 브라우저에 저장합니다.

## 행사

이틀·10개 예시 세션, 날짜/분야 필터, 검색과 북마크, 연사·내용·배울 점이 다른 상세 화면, 개인 메모, 중첩된 가상 행사장 배치도, 세션 선택, 실제 구간 비교를 통한 시간 충돌 감지, 명시적 교체 확인, 만석 데모 대기 표시, 날짜별 개인 시간표와 쉬는 시간, 총 소요시간, 삭제와 실행 취소, 분야별 비중복 시간표 자동 구성, 시간표 공유, UTC 기준 ICS 내보내기, 선택 가능한 10분 전 캘린더 알림, 데모 이름·QR 패스, 체크인 시연, 워터마크된 SVG 패스 내보내기.

세션 추천은 AI 서비스 호출이 아니라 **끝나는 시간이 빠른 순으로 고르는 결정적 구간 선택**입니다. 실제 좌석 예약이 없으며, 가상의 날짜와 모든 캘린더 제목에 데모 표시를 넣었습니다. ICS를 가져오는 것은 사용자가 선택하며 이 웹앱이 캘린더 계정에 직접 쓰지 않습니다. 브라우저 푸시 알림은 제공하지 않습니다. 패스에는 `NOT VALID FOR ENTRY`를 명시합니다.

## 재사용한 새 공통 기능

- `demo-models.js`: DOM 없는 가격·쿠폰·장바구니·시간 충돌·시간표·ICS 모델
- `demo-ui.js`: 로컬 저장, 옵션 그룹, 수량 컨트롤, 빈 상태, 확인 시트, 예시 간 이동, 내보내기와 공유 대체 동작
- `demo-apps.css`: 기존 팔레트·카드 형태를 유지하는 앱별 레이아웃

사용자 텍스트는 `textContent`/DOM 생성 API로만 넣습니다. SVG 패스는 XMLSerializer로 만들며 입력 이름을 HTML로 삽입하지 않습니다. 기존 `tabbable` 모듈의 키보드 이동과 시트 포커스 복원을 그대로 사용합니다.

## 저장과 권한

예시별 `localStorage` 키를 분리합니다. 설정에서 각 예시만 초기화할 수 있고, 공유된 움직임 줄이기 설정은 유지합니다. 저장이 차단되면 현재 메모리 상태로 실행되며 설정에서 지속 저장 불가를 알립니다. 실제 이름·이메일·주소·카드 정보를 요구하지 않습니다. 외부 계정/서버/결제 API에 쓰는 요청이 없습니다. 폰트 CSS 외의 원격 자산은 필요하지 않습니다. 폰트 바이너리는 키트에 포함하지 않습니다.

## 테스트

```sh
node --test ui-kit/tests/*.test.mjs
python ui-kit/build_preview.py
python ui-kit/tests/apps.spec.py --browser chromium
python ui-kit/tests/apps.spec.py --browser webkit
# 기존 수업·갤러리도 함께 회귀 검사
```

새 검사에는 가격 계산, 쿠폰 조건, 병합과 제한, 저장 복원, 삭제 취소, 주문 단계, 충돌 교체, 대기 표시, 메모, 중첩 모달, ICS/패스/영수증 다운로드, 초기화 격리, 화면 넘침, 88px 아일랜드 유지가 포함됩니다. CI는 실제 HTTP origin과 localStorage를 사용합니다. 제한된 로컬 환경의 테스트는 별도 메모리 shim을 사용하며 결과에 구분해 표시합니다. Chromium/WebKit 검사는 실제 iPhone 실기기·VoiceOver 인증이 아닙니다.

ICS 형식은 RFC 5545에 맞춰 CRLF, UTF-8 바이트 기준 줄 접기, 텍스트 이스케이프, UTC 시작/종료 시각과 안정적인 UID를 사용합니다. 사용한 웹 API 참고 문서는 MDN localStorage와 Navigator.share이며, 공유가 지원되지 않으면 복사/텍스트 선택으로 대체합니다.

기존 TripFit 출처와 외부 라이선스 고지는 유지합니다. 이 예시에 새로 쓴 코드가 원본에서 추출한 부품의 권리 조건을 바꾸지 않습니다.
